Quick Actions: Reset Invoice to Draft

Stop wasting clicks. Reset any posted invoice to draft in a single button press.

FREE MODULE - Download and Install at No Cost

The Problem

In standard Odoo, resetting a validated invoice to draft requires multiple steps and confirmations scattered across menus. For busy accounting teams posting and correcting dozens of invoices per day, this is a significant waste of time.

The Solution

This module adds a single bright "Reset to Draft" button directly inside the invoice header bar. One click, one confirmation popup, and your invoice is back in Draft state. The button is restricted to Accounting Managers only, keeping your data secure. Standard accounting clerks will never see it.

How It Works

1

Open a Posted Invoice

Navigate to any invoice with status "Posted" in Odoo Accounting.

2

Click "Reset to Draft"

The orange button appears in the top action bar. Click it and confirm the popup.

3

Done

The invoice is instantly back in Draft state and ready to be corrected and re-posted.

What is Included

One-Click Reset

A single orange button in the invoice header eliminates all the multi-step menu navigation.

Manager-Only Access

The button is hidden from all standard users. Only Accounting Managers will see it, protecting your data.

Confirmation Popup

A confirmation dialog prevents accidental resets, giving you one final safety check before the action runs.

Zero Enterprise Dependencies

Depends only on the standard "account" module. Runs perfectly on any Odoo 17 Community server.
